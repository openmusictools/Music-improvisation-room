# חדר אלתור 🎹 - ליווי אישי לתרגול אלתור בפסנתר

**חדר אלתור** היא אפליקציית ווב (Single-Page Web App) קלה, אינטראקטיבית ועצמאית (Self-contained), שנועדה לספק לנגני פסנתר מסגרת אימון ממוקדת בת 15 דקות לתרגול אלתור חופשי ופיתוח שמיעה מוזיקלית.

![App Preview](https://img.shields.io/badge/Status-Ready_for_Use-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## ✨ תכונות מרכזיות

* **🎯 אימון ממוקד ב-15 דקות:** חלוקה מובנית ל-5 דקות תרגול סולם ו-10 דקות אלתור חופשי.
* **🎲 הגרלת סולמות אקראית:** בחירה מתוך 26 סולמות (מאג'ור ומינור) ליצירת גמישות תפיסתית ומניעת קיבוע.
* **🎨 מחולל קונספטים ומקצבים:**
  * הגבלת תווים מבוססת משקלים (פיתוח יצירתיות מתוך הגבלה).
  * הגדרת קצב חופשי (Rubato) או קצב קבוע (BPM) כולל מחולל מקצבים אינטראקטיבי.
* **🎹 תצוגת מקלדת ויזואלית:** הבלטה בזמן אמת של התווים הנבחרים על גבי מקלדת פסנתר (SVG).
* **⏱️ מטרונום וטיימר מובנים:** כולל חיווי קולי (Chime/Tick) ואפשרות השתקה.
* **💡 דגשים פדגוגיים:** טיפים והסברים תאורטיים בכל שלב (פיתוח אודייציה, מניעת עומס קוגניטיבי, הולכת קולות ורפלקציה).
* **🌐 עבודה אופליין מלאה:** קובץ HTML יחיד שאינו תלוי בשרת או בספריות חיצוניות.

---

## 🚀 איך מריצים?

אין צורך בהתקנה או בשרת local! 

1. הורד את הקובץ `index.html`.
2. פתח אותו בכל בדפדפן (Chrome, Firefox, Safari, Edge).
3. פתח את הרמקולים, שב ליד הפסנתר והתחל לנגן!

---

## 🛠️ טכנולוגיות

* **HTML5 & CSS3:** עיצוב מודרני מבוסס משתנים (CSS Variables), גראדיאנטים ואנימציות מותאמות.
* **Vanilla JavaScript (ES6+):** ניהול מצב (State Management) נקי ללא ספריות חיצוניות.
* **Web Audio API:** יצירת צלילי חיווי, מטרונום והשמעת המקצבים באופן סינתטי בדפדפן.
* **SVG:** רנדור דינמי וקליל של מקלדת הפסנתר.
